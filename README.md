# 🎓 고입패스 365 (GoipPass 365)
> **중학교 3학년 담임선생님을 위한 고입 진학 지도 & 전기·후기 원서 통합 관리 포털**  
> *Supabase Realtime & PostgreSQL DB + GitHub CLI + React 19 / TypeScript / Tailwind CSS v4*

---

## 🌟 프로젝트 소개
**고입패스 365 (GoipPass 365)**는 중학교 3학년 2학기, 담임선생님들의 가장 중요하고 막중한 업무인 **고입(고등학교 입학) 원서 접수 및 진학 지도**를 체계적이고 빈틈없이 지원하기 위해 개발된 전용 에듀테크 웹 서비스입니다.

- **전기고/후기고 전형 일정 캘린더 & D-Day 알림**: 영재교, 과고, 마이스터고, 특성화고, 예체능고, 자사고, 외고/국제고, 일반고별 원서 접수 및 마감일 관리
- **학생별 내신 성적 & 희망 고등학교 관리**: 내신 석차백분율(%), 총점, 전교 석차, 1·2·3지망 희망학교
- **전기 & 후기 원서 접수 트래커**: 어디에 원서를 넣었는지, 원서 작성일, 마감일, 서류 확인, 최종 합격 여부
- **🚨 법령 기반 이중지원 금지 자동 감지기**: 전기고 최종 합격자의 후기고 이중지원 시도를 실시간으로 감지하고 경고
- **학부모 동의서 & 상담 이력 수합**: 원서 지원 동의서 확인, 누적 진학 상담 횟수 및 특이사항 메모
- **나이스 & 교육청 제출용 엑셀(CSV) 일괄 출력**: 학급 고입 현황 보고서 원클릭 다운로드

## 🛠️ 기술 스택 (Tech Stack)

| 영역 | 기술 스택 | 설명 |
|---|---|---|
| **Frontend** | React 19, TypeScript, Vite | 빠르고 안정적인 최신 웹 프레임워크 |
| **Styling** | Tailwind CSS v4 | 직관적인 고입 테이블 및 반응형 카드 UI |
| **Backend & DB** | Supabase (PostgreSQL 17) | 서울 리전 (`ap-northeast-2`) 호스팅 |
| **Realtime** | Supabase Realtime (WebSocket) | 원서 진행 상태 및 성적 데이터 실시간 동기화 |
| **Audio FX** | Web Audio API | 저장 완료 및 상태 변경 효과음 합성 엔진 |
| **Repo Management** | Git & GitHub CLI (`gh`) | 소스코드 형상 관리 및 원격 저장소 배포 |

## 🚀 주요 기능 (Key Features)

### 1. 📊 고입 종합 상황판 (Dashboard)
- 학급 재적, 남/여 비율, 내신 평균 석차백분율(%) 산출
- 전기고 지원자 수, 전기고 최종 합격자 수(고입 확정 🎉), 후기고 원서 접수자 수, 상담 요망 학생 실시간 카운트
- **가장 임박한 원서 마감 일정 D-Day 배너** 자동 표시 (D-3, D-Day, 접수종료)

### 2. 📅 전기고 · 후기고 전형 일정 캘린더
- 전기고 (과고, 마이스터고, 특성화고 특별/일반, 예술고, 체육고 등) 및 후기고 (외고, 자사고, 일반고 평준화)
- 원서 접수 시작일, 마감일, 면접/실기일, 합격자 발표일 타임라인
- 학교별 전형 일정 자유 추가, 수정, 삭제 및 D-Day 자동 계산

### 3. 🧑‍🎓 고입 원서 & 내신 통합 관리표 (Master Table)
- **내신 성적 관리**: 석차백분율(%), 300점 만점 총점, 전교 석차
- **희망 학교**: 학생 및 학부모 1·2·3지망 고등학교
- **전기고 원서 지원 관리**: 지원 고교, 학과/계열, 전형 구분, 원서 작성일, 마감일, 상태(`미지원`, `원서작성중`, `접수완료`, `1차합격`, `최종합격`, `불합격`), 필수 구비 서류 체크
- **후기고 원서 지원 관리**: 1지망 고교, 2지망 고교, 전형 구분, 원서 작성일, 마감일, 상태(`작성대기`, `원서작성중`, `접수완료`, `배정완료`), 최종 배정 고교
- **학부모 동의서 수합**: 원클릭 토글 (제출완료 / 미제출)
- **담임 진학 상담 메모**: 상담 횟수 및 특이사항 누적

### 4. 🚨 이중지원 금지 자동 경고 시스템
- 초·중등교육법 시행령 제85조에 따라, 전기고에 최종 합격한 학생이 후기고 원서를 작성하거나 접수할 경우 **붉은색 경고 배너 및 학생 행 하이라이트**로 실시간 경고하여 입학 취소 사고를 원천 방지합니다.

### 5. 🖨️ 나이스 & 진로상담부 제출용 엑셀(CSV) 다운로드
- 학급 25~30명 전체 학생의 내신 성적, 희망교, 전기/후기 지원처, 전형 상태, 학부모 동의서 제출 여부, 담임 메모를 정형화된 CSV 파일로 원클릭 다운로드

## 🗄️ Supabase 데이터베이스 구조

1. `goip_classes`: 학급 정보 (학년도, 학년, 반, 학교명, 담임명, 비밀번호)
2. `goip_schedules`: 학교별 전형 일정 캘린더 (전기/후기 구분, 원서접수일, 면접일, 발표일, 비고)
3. `goip_students`: 학생별 내신 성적, 희망학교, 전기고 원서 현황, 후기고 원서 현황, 학부모 동의서, 상담 메모
- 모든 테이블에 `supabase_realtime` 및 RLS 정책 적용
